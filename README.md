# Nexus Store — demo de e-commerce

Projeto de portfólio de interface de loja online. Abra `index.html` ou hospede em GitHub Pages.

## Funcionalidades
- Catálogo ilustrativo responsivo
- Pesquisa de produtos e filtro por categoria
- Modal de simulação de pedido com validação básica
- Feedback de interface

## Segurança e escopo
**Não é uma loja real.** Produtos, avaliações e preços são demonstrações. O formulário não realiza compra, não envia e-mail, não processa pagamento e não envia dados a servidores. O webhook n8n anteriormente exposto no frontend foi removido.

Para implantar um e-commerce real, seriam necessários backend, autenticação segura, integração de pagamentos confiável e adequação à LGPD.
